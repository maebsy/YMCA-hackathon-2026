# 72hours 문서 안내

72hours는 공개 GitHub 저장소 검사, 한국어 대응 안내, 사용자 AI 에이전트로 수정 지시 전달, 수정 후 재검사를 연결합니다. 웹과 원격 MCP는 같은 백엔드를 사용합니다.

이 문서들은 현재 코드의 지원 범위를 설명합니다. 기본 구성과 구현된 선택 설정을 구분합니다. 미구현 기능과 초기 사업화 계획은 포함하지 않습니다.

## 처음 사용하는 사람

- [시스템 흐름과 지원 범위](system-flow.md): 웹·MCP·보안엔진·로컬 LLM의 역할
- [MCP 연결 및 사용법](../integrations/mcp-handoff/DISTRIBUTION.md): 원격 서버 연결, 점검·수정 지시·재검사
- [리포트와 사고 신고 초안](reports.md): 출력 형식, 사용자 확인, API
- [수정 전후 실행 검증](verify.md): 데모 과녁, 기준 수정본/AI 모드, 실제 검증의 한계

## 문서 유지 원칙

- 기능 설명은 해당 코드·설정·테스트와 함께 갱신합니다. 기본 설정과 운영 서버의 현재 값을 구분합니다.
- 수치는 실행 날짜·대상·환경·커밋과 함께 기록합니다. 단위 테스트 통과를 탐지율이나 실서비스 안전성으로 표현하지 않습니다.
- 같은 사용법은 한 곳에서 관리하고 다른 문서는 링크합니다. 문서 이동 시 상대 링크도 함께 고칩니다.
- 서비스 구성과 비밀값을 분리합니다. 실제 키·토큰·개인 경로·비공개 원본 로그는 문서에 넣지 않습니다.
