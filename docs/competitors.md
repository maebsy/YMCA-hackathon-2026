# 72hours 핵심 경쟁사

기준일 2026-10-31. 우리 고객(예산이 부족한 중소기업·바이브코딩 사이트)과 겹치고, 취약점을 찾는 데서 끝나지 않고 고치는 쪽까지 겹치는 곳만 골랐습니다.

| 업체 | 왜 경쟁사인가 | 우리 차별점 |
|---|---|---|
| **Vibe App Scanner** (해외) | 바이브코딩 앱 전용. 소스·배포 URL 점검과 AI 수정 지원까지 해서 타깃·기능이 가장 가까움 | 72시간 완료 기준, KISA 신고서 지원, 한국어 비전공자 설명 |
| **라온시큐어 라온 PTaaS** (국내) | 중소기업 대상 월 구독 보안 점검. 국내에서 "예산 부족한 중소기업에 구독으로 판다"는 점이 가장 겹침 | 사람 해커가 아닌 자동 점검이라 더 저렴하고, 매일 검사하며 수정 지시까지 제공 |
| **Aikido** (해외) | 스타트업·중소기업 대상. 스캔부터 자동 수정까지 하고 무료 티어가 있어 "무료로 쓸 대안"이 됨 | 개발자용이 아닌 비개발자 눈높이 설명, 72시간 기준과 신고 지원 |
| **AI스페라 (+KISA 무상 점검)** (국내) | 중소기업에 URL만으로 무료 점검 제공. 고객이 "공짜로 하자"며 고를 수 있는 선택지 | 한 번 점검하고 끝이 아니라 매일 검사하고, 수정 지시와 재검사로 완료까지 감 |

## 제외한 곳

- **영역이 다름**: SK쉴더스(보안관제), 모니터랩(웹방화벽), 안랩(PC 보안)
- **고객이 다름**: Snyk·GitHub Copilot Autofix(개발자 도구), Horizon3.ai·XBOW·Pentera(대기업), 티오리 Xint(대규모 기업 점검)
- **겹치는 부분이 작음**: Intruder·Astra Security(중소기업 대상이지만 외부 스캔·보고서 위주)

## 참고

- '우리 차별점'은 `docs/system-flow.md`의 설계 기준이며 구현 후 검증이 필요합니다.
- AI스페라+KISA 무상 점검은 2025년 기사 기준 "연말까지"였고, 2026년에도 하는지는 확인하지 못했습니다.
