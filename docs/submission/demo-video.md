# 시연 영상·쇼츠

시연 영상은 2분 이내로 알려져 있습니다([README](README.md) 결정 필요 ①). 쇼츠는 형식과 필수 여부가 확인되지 않아, 아래는 세로 45초 기준 초안입니다.

## 1. 2분 시연 영상 콘티

**원칙**: 실제 서비스 화면만 씁니다. 기다리는 구간은 빨리 감되 **실제 걸린 시간을 자막으로** 적습니다. 예제 데이터 화면은 쓰지 않습니다.

| 시간 | 화면 | 자막·내레이션 |
|---|---|---|
| 0:00–0:10 | 데모 사이트(AI로 만든 예약·주문 페이지) 첫 화면 | "AI로 만든 가게 사이트. 보안은 괜찮을까요?" |
| 0:10–0:25 | 72hours 첫 화면에 GitHub 주소 입력 → 검사 시작 | "GitHub 주소 하나면 됩니다." |
| 0:25–0:40 | 검사 진행 (빨리 감기, 자막 "실제 [N]초") → 결과 목록 | "스캐너 3종과 바이브코딩 규칙 21개로 찾았습니다." |
| 0:40–1:00 | 가장 위험한 1건 열기: 우선순위, 쉬운 설명, Red 검증 표시, OS별 명령 | "지금 바로 고쳐야 할 것부터, 사장님 말로." |
| 1:00–1:25 | AI 코딩툴(Claude Code 또는 Cursor) 화면: MCP로 수정 지시 받기 → 코드 수정 | "수정 지시는 MCP로 AI 코딩툴에 바로 갑니다." |
| 1:25–1:40 | 재검사 → 해당 건이 "해결됨"으로 바뀜 | "다시 검사해서 정말 고쳐졌는지 확인합니다." |
| 1:40–1:52 | 완료 리포트 화면 (또는 신고서 초안 화면 한 컷) | "완료 리포트, 사고가 의심되면 신고서 초안까지." |
| 1:52–2:00 | 로고와 한 줄 | "72hours. 찾고, 고치고, 확인합니다." |

### 녹화 전에

- [ ] 데모 저장소가 정해졌고(결정 필요 ⑥), #69 허용 목록에 들어 있음
- [ ] 데모 저장소에서 처음부터 끝까지 한 번 돌려 보고 각 구간 실제 소요 시간을 적어 둠
- [ ] AI 코딩툴에 MCP가 연결돼 있고, 고칠 1건이 재검사에서 실제로 "해결됨"이 되는지 확인
- [ ] 브라우저 확장·북마크바·알림 끄기, 화면 배율 100%, 1920×1080
- [ ] 화면에 **공개 URL, 시연 비밀번호, 토큰, 개인 이메일**이 보이지 않음 (주소창 가리기)

### 녹화

- 같은 흐름을 **3번 녹화**해 가장 깨끗한 것을 씁니다. 라이브 시연이 실패할 때 이 영상을 대신 틉니다.
- 화면 녹화는 소리 없이 하고, 내레이션은 나중에 따로 녹음하거나 자막만 씁니다.
- 원본 영상은 팀 Drive에 바로 올립니다.

### 편집

- 2:00을 넘지 않습니다. 넘치면 0:00–0:10과 1:40–1:52를 줄입니다.
- 빨리 감은 구간에는 실제 걸린 시간을 자막으로 남깁니다.
- MP4로 저장하고, 파일 이름에 팀명을 넣습니다. 예: `YMCA_72hours_demo.mp4`

## 2. 쇼츠 (세로 9:16, 45초)

| 시간 | 화면 | 자막 |
|---|---|---|
| 0–3초 | 큰 글자 | "AI로 만든 내 사이트, 손님 정보가 밖에서 보인다면?" |
| 3–10초 | 경고 원문(CVE 번호·규칙 ID)을 확대 | "보안 경고는 이렇게 생겼습니다. 무슨 말인지 아시겠어요?" |
| 10–22초 | 72hours의 쉬운 설명 카드 | "72hours는 사장님 말로 바꿔 줍니다. 지금 고칠 것부터." |
| 22–35초 | AI 코딩툴이 고치고 재검사 "해결됨" | "AI 코딩툴이 고치고, 다시 검사해서 확인까지." |
| 35–45초 | 로고, 팀명 | "72hours · 팀 YMCA" |

- 2분 시연 영상 원본에서 잘라 만들면 추가 녹화가 필요 없습니다.
- 배경 음악을 쓰면 출처와 라이선스를 `docs/external-resources.md` "기타"에 적습니다.

## 3. 라이브 시연을 한다면 (2차 발표)

- 시연 순서는 1장 콘티와 같게 하고, 검사를 미리 한 번 돌려 둔 결과 화면을 탭으로 열어 둡니다.
- 공개 서버가 느리거나 실패하면 30초 안에 녹화 영상으로 바꿉니다. 영상 파일은 발표 노트북 바탕화면에 둡니다.
- 로컬 Compose(`docker compose up --build --watch`)를 백업으로 띄워 둡니다.
