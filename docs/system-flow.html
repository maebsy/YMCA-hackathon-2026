찾기

검증된 도구 + 우리 규칙

코드, 라이브러리, 비밀키, 설정 실수를 찾습니다. 비밀키는 최신 커밋의 현재 파일을 검사하고, 재검사에서 지워진 키는 “키 폐기·재발급 필요”로 알립니다. 과거 커밋 속 비밀키와 웹셸 탐지는 추후 추가합니다. 모두 유료 서비스에 써도 되는 라이선스입니다.

고치기

GPU LLM Red–Blue

Blue가 쉬운 설명과 수정 지시를 쓰고 Red가 공격해 봅니다. 통과한 수정만 대시보드와 MCP로 코딩툴에 전달합니다.

72시간

해결 + 리포트, 사고 시 신고 서포트

발견 순간 타이머가 시작되고 완료 리포트 전달로 멈춥니다. 사고가 의심되면 24시간·72시간 신고서 작성을 돕습니다.

증명

GPU 효과를 숫자로
