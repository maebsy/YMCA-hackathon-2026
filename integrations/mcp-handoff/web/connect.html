내 코드를 수정하세요.

같은 브라우저에서 검사한 결과를 선택하고, 연결 문장을 AI 에이전트에게 전달하세요. 파일 설치는 필요 없습니다.

웹에서 검사하기 ↗

1. 실제 검사 결과 확인

브라우저의 검사 결과를 확인하고 있습니다.

클릭하면 수정 지시와 검사 식별 정보만 별도 MCP 저장소에 전달합니다. 코드 원문·키·공격 시나리오는 보내지 않습니다. 연결은 24시간 뒤 만료되며 직접 폐기할 수 있습니다.

2. 내 AI 에이전트에게 전달

이 문장에는 해당 결과를 읽는 비밀 연결이 들어 있습니다. 본인의 AI 에이전트에만 전달하세요. 저장소·공개 채팅에는 올리지 마세요.

3. 수정 결과 확인

에이전트가 저장소·검사 커밋을 확인하고 수정 제안을 읽습니다. 허용한 범위에서 코드를 수정하고 테스트한 뒤, 웹에서 다시 검사해 남은 문제를 확인하세요.

해석 중에는 현재 완료된 결과만 전달됩니다. 새 해석이나 재검사 결과를 넘기려면 연결을 새로 만드세요. 다른 저장소나 다른 커밋에는 자동 적용하지 않습니다.

현재 브라우저에 저장된 결과를 전달하는 방식입니다. 브라우저 export는 서버가 서명한 원본이 아니므로 에이전트가 실제 코드 근거를 다시 확인합니다. AI 도구에 따라 최초 MCP 연결 승인·재접속이 필요할 수 있습니다.
