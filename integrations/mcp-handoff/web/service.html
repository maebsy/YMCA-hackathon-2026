1. AI 앱에 서버 주소 등록

사용할 AI 앱에서 아래 서버를 한 번 추가하세요. 프로그램이나 검사 결과 파일을 다운로드할 필요가 없습니다.

이름 72hours · 인증 No authentication / No sign in (현재 공개 데모)

Claude · 웹 / Desktop
  1. Customize 또는 Settings에서 Connectors를 엽니다.
  2. Add custom connector를 선택하고 이름과 위 서버 URL을 입력합니다.
  3. 인증은 No sign in으로 확인하고 추가한 뒤, 대화의 Connectors에서 72hours를 켭니다.

Claude 열기 ↗ · 공식 연결 안내

팀·기업 계정은 관리자가 먼저 커넥터를 추가해야 할 수 있습니다. 메뉴 표시는 계정·버전에 따라 다릅니다.
ChatGPT · 지원되는 계정 / 워크스페이스
  1. 웹 ChatGPT의 Plugins → + → Add custom MCP server를 엽니다.
  2. 이름과 위 서버 URL을 입력하고 인증은 No authentication을 선택합니다.
  3. 안내를 확인해 생성한 플러그인을 설치한 뒤, 새 대화에서 @로 72hours를 선택합니다.

ChatGPT 열기 ↗ · 공식 연결 안내

앱·커넥터 메뉴로 표시되는 버전에서는 사용자 지정 MCP 추가 메뉴를 이용하세요. 메뉴가 없으면 계정 지원 여부와 워크스페이스 권한을 확인해야 합니다.
기타 AI · 코딩 에이전트

앱의 MCP 서버 추가에서 Streamable HTTP와 위 URL을 지정하세요. 현재 데모는 API 키·OAuth Client ID가 필요 없습니다.

Cursor에 연결VS Code에 연결

설정 JSON 받기 · Claude Code·Codex 설정 안내

JSON은 mcpServers 형식입니다. 앱별 형식을 확인하고 기존 설정을 보존하세요. stdio 전용 앱에는 별도 브리지가 필요합니다.

2. 연결 확인 후 대화로 사용

앱에서 72hours를 활성화한 다음 아래 문장으로 연결을 확인하세요.

연결이 확인되면 검사할 공개 GitHub 저장소 주소와 함께 “이 저장소를 검사하고 GPU 분석으로 수정 방법과 리포트를 정리해줘”라고 요청하세요.

웹 채팅: 저장소 주소로 검사·분석·수정 제안·리포트를 이용합니다.
코딩 에이전트: 같은 기능을 사용하면서, 허용된 프로젝트 파일을 직접 수정하고 테스트할 수 있습니다.

이 페이지는 AI 앱의 등록 완료 여부를 알 수 없습니다. 앱에서 실제 도구 호출이 성공하는지 확인하세요.

어디에서 무엇이 실행되나요?

검사·GPU 분석·리포트는 72hours 서버에서 실행되고, 코드의 직접 수정은 파일 접근 권한이 있는 AI 에이전트의 프로젝트에서 수행합니다. 검사 결과를 내려받아 다시 올릴 필요가 없습니다.

공개 GitHub 저장소의 기본 브랜치를 검사합니다. 원격 재검사는 GitHub에 게시된 커밋을 확인하므로, 아직 내 PC에만 있는 수정은 로컬 테스트로 검증합니다.

GPU 분석에는 몇 분이 걸릴 수 있습니다. 작업 공간은 24시간 유지되며 최대 16건의 검사·분석을 접수할 수 있습니다. 시연 주소는 터널 재시작 시 변경될 수 있습니다.
